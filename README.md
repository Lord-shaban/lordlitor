## 🎯 حول التطبيق

**Lordlitor** تطبيق تعليمي تفاعلي مستوحى من [Duolingo](https://www.duolingo.com/) لتدريب القدرات الذهنية والرياضيات. مصمم لمساعدة الطلاب على التحضير لاختبارات القدرات من خلال تمارين متنوعة بأنماط مستخلصة من **68 سؤال امتحاني حقيقي**.

### 🧠 الحساب الذهني — 21 نمط سؤال

مبني على تحليل عميق لأسئلة الامتحانات الحقيقية:

```
العمليات المركبة (14 نمط):
  a×b+c  │  a×b×c  │  a×b+c×d  │  a×b-c×d  │  a×b÷c+d
  a×b+c÷d  │  a×b÷c×d  │  a+b×c×d  │  a÷b×c+d  │  a÷b×c
  a×b÷c-d  │  a÷b×c-d  │  a÷b÷c×d  │  a-b×c-d  ...وأكثر

مسائل لفظية (7 أنماط):
  كسور   →  ثلث، نصف، ربع، خمس، سدس، ثمن...
  وقت    →  ثواني ↔ دقائق ↔ ساعات ↔ أيام
  تقويم  →  أشهر، عقود، عدّ الوحدات
  هندسة  →  مجموع أضلاع الأشكال
  نسب %  │  عدد مفقود  │  ضعف/نصف  │  حاصل ضرب
```

### 🏋️ جدول الضرب (1-20)

- تدريب شامل لكل جدول على حدة
- **نظام إتقان**: الأسئلة الخاطئة تُعاد حتى تُجيب على الكل صح ✅
- ضمان عدم الانتقال بدون إتقان كامل

## 📊 نظام الصعوبة

| المستوى | نطاق الأرقام | العمليات | النتيجة | مثال |
|:-------:|:-----------:|:--------:|:------:|:----:|
| 🟢 **سهل** | 2 — 20 | 1-2 | < 200 | `14 × 4 ÷ 2 + 18` |
| 🟡 **متوسط** | 10 — 100 | 2-3 | 100 — 600 | `9 × 6 + 12 × 4` |
| 🔴 **صعب** | 50 — 1000+ | 3-4+ | 500+ | `955 - 133 × 6 + 459` |

> **📌 نظام الصعوبة الذكي**: 90% من الأسئلة تكون من المستوى المُختار مع 10% تنوع — لضمان تجربة عادلة ومتدرجة.

## 🚀 البدء السريع

### المتطلبات
- [Flutter SDK](https://flutter.dev/docs/get-started/install) `3.9+`
- [Dart](https://dart.dev/) `3.9+`
- Android Studio أو VS Code
- جهاز Android/iOS أو محاكي

### التثبيت والتشغيل

```bash
# 1. استنساخ المشروع
git clone https://github.com/Lord-shaban/lordlitor.git
cd lordlitor

# 2. تثبيت الحزم
flutter pub get

# 3. تشغيل في وضع التطوير
flutter run
```

### البناء للإنتاج

```bash
# Android APK
flutter build apk --release

# Android App Bundle (Google Play)
flutter build appbundle --release
```

### إعداد اختياري

```bash
# إنشاء Native Splash Screen
dart run flutter_native_splash:create

# إنشاء أيقونات التطبيق
dart run flutter_launcher_icons
```

## 📈 نظام التقدم

```
┌─────────────────────────────────────────────────┐
│  📊 الإحصائيات                                  │
│                                                 │
│  🔥 Streak    ⭐ XP       ✅ دروس   🏆 كومبو  │
│  ─────────    ──────      ──────    ──────── │
│  أيام متتالية  نقاط خبرة   مكتملة    أفضل سلسلة │
│                                                 │
│  📈 التقدم للمستوى التالي: ████████░░ 75%       │
│  🎯 نسبة الدقة: 85%   📝 صح/مجموع: 340/400    │
└─────────────────────────────────────────────────┘
```

- **XP**: 10 نقاط لكل إجابة صحيحة + مكافآت إضافية
- **كومبو**: 3+ إجابات متتالية = ×1.5 | 5+ = ×2 | 8+ = ×3
- **المستويات**: كل 100 XP = مستوى جديد
- **Streak**: تدريب يومي متتالي
